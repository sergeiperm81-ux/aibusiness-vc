# SEO 60-Day Roadmap (Weekly)

Last updated: 2026-04-30

## Goal
Grow non-brand organic traffic with a repeatable editorial + technical SEO system.

## Success Targets (by Day 60)
- +40% non-brand clicks.
- +30% URLs in Top 10.
- +20% CTR uplift on top-impression pages.
- 0 critical canonical/indexation issues.

## Week 1 — Technical Baseline
- Canonical/indexation cleanup.
- Validate sitemap coverage and private-route exclusion.
- Confirm robots/sitemap alignment.
- Fix obvious metadata and encoding defects.

Done:
- Home canonical now resolves to `https://aibusiness.vc/`.
- Added technical checklist in `docs/gsc-ready-checklist.md`.

## Week 2 — GSC Operations Setup
- Create a tracked URL backlog (P0/P1/P2).
- Define weekly GSC operating template.
- Set review cadence and owners.

Done:
- Added `docs/seo-priority-board.csv`.
- Added `docs/seo-priority-summary.md`.
- Added `docs/gsc-weekly-review-template.md`.
- Added generator script `scripts/generate-seo-priority-board.js`.

## Week 3 — CTR Sprint #1
- Pull GSC query/page data for P0/P1 URLs.
- Rewrite title/meta for top low-CTR pages.
- Re-test snippets after recrawl.

KPI:
- +10-15% CTR on touched pages.

## Week 4 — Content Quality Sprint #1
- Upgrade top weak pages in each section with deeper analysis and clearer monetization angle.
- Add stronger unique insights and factual support.
- Standardize intros and internal linking quality.

KPI:
- Better avg position trend and improved engagement quality.

## Week 5 — Topical Cluster Reinforcement
- Build or upgrade section hub pages.
- Tighten hub-spoke internal linking.
- Add missing high-intent support pages for each section.

KPI:
- More ranking queries per section cluster.

## Week 6 — Distribution + Links
- Weekly data-led article campaign.
- Outreach for links/mentions from relevant publications and creators.
- Repurpose top pieces for social/discussion channels.

KPI:
- +10 to +20 new referring domains.

## Week 7 — Refresh Loop
- Refresh aging high-potential pages with new data and sources.
- Update dates where materially improved.
- Link refreshed pages from fresh posts.

KPI:
- +20-30% clicks on refreshed URLs (2-3 week lag).

## Week 8 — Consolidation + Scale
- Compare 60-day cohort vs baseline.
- Freeze winning title/meta and content patterns.
- Expand automation prompts with winning editorial patterns.

KPI:
- Stable week-over-week growth and lower volatility.

## Weekly Ritual
1. Run `npm run seo:board`.
2. Review GSC with `docs/gsc-weekly-review-template.md`.
3. Update `docs/seo-priority-board.csv` statuses.
4. Ship 5-10 high-impact URL improvements.
5. Log wins/losses and next actions.
